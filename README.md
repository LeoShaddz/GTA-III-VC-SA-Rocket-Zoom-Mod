# GTA III/Vice City/San Andreas Rocket Zoom Mod

This mod allows you to zoom in when aiming with RPGs, similar to the Definitive Edition. Sensitivity decreases when zooming in, just as it does with sniper rifles in the original games. This mod supports controllers.

# Installation

**III and VC**:

1. Install the Ultimate Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.III-VC-SA.Rocket.Zoom.Mod.v1.0.zip"
3. Copy the "Rocket Zoom" folder into the "modloader" folder, which is located in your game's root directory.
4. Done

**SA**:

1. Install the Silent's Asi Laoder and Modloader in in the game's root folder
2. Extract the file "GTA.III-VC-SA.Rocket.Zoom.Mod.v1.0.zip"
3. Copy the "Rocket Zoom" folder into the "modloader" folder, which is located in your game's root directory.
4. Done
