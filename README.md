# GTA III/Vice City/San Andreas Rocket Zoom Mod

This mod allows you to zoom in when aiming with RPGs, similar to the Definitive Edition. Sensitivity decreases when zooming in, just as it does with sniper rifles in the original games. This mod supports controllers.
